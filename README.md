# Is It Real? — Asia Adventure

Gamified digital-literacy demo for the competition: investigate viral claims before you share.

## Run

```bash
npm install
npm run dev
```

Then open the local URL Vite prints (usually http://localhost:5173).

## Demo path

1. **World map** — click glowing **Asia**
2. **Asia adventure** — open **Bến Thành Market**
3. **Mission intro → Case brief →** three investigation steps (drag & drop)
4. **Results → Stage complete**

Tagline: **Travel safe, share wisely.**
